# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Wait ("Great Stock Takes Time") is a SwiftUI stock-alert app. The user keeps a watchlist where each stock has a **price ladder** (`buyLow`, `buyHigh`, `fair`, `trim`, `sell`). The app shows where the current price sits on that ladder as a temperature (0–100) and a `LadderStatus`: deep buy, buy zone, watch, at or above fair, trim, sell, or no anchors. The repo has an iOS app (iOS 17), a WidgetKit extension, and a watchOS 10 app. CI runs on Bitrise; its config lives in Bitrise, not in this repo.

The modernization plans live in `docs/superpowers/plans/`. Start with `2026-11-22-wait-00-overview.md`. Plans 01 (foundation) and 02 (ladder and features) are done. The legacy iOS modules, Money, Alamofire and SwiftyJSON are gone from the package. The watch app is still the old copy-based one until plan 03.

## Commands

The Xcode project is **generated by XcodeGen** from `Wait/project.yml`. `Wait/Wait.xcodeproj` is committed, so Xcode and CI don't need XcodeGen. **Never hand-edit `project.pbxproj`**: change `project.yml` and regenerate. After regenerating, check that `Wait/Wait.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/Package.resolved` still exists.

`xcodebuild`/`xcodegen` need to run unsandboxed in agent sessions. SwiftPM's manifest sandbox can't nest, and it fails with `sandbox_apply: Operation not permitted`.

```sh
cd Wait && xcodegen generate                 # after editing Wait/project.yml
scripts/build-app.sh                         # app + widget (+ embedded watch), iPhone 17 / iOS 27.0
scripts/build-app.sh WaitWatch               # watch app
scripts/test-waitkit.sh                      # every WaitKit test target (scheme WaitKit-Package)
scripts/test-waitkit.sh DomainTests/PriceLadderTemperatureTests   # one suite

# Scan tracked files for hard-coded credentials (also a CI step)
scripts/check-secrets.sh

# Format and lint (configs live in Wait/, so run from there; neither runs as a build phase)
cd Wait && swiftformat .     # needs `brew install swiftformat`
cd Wait && swiftlint

# Dead-code scan (run by hand; the old "Unused Code" target is gone)
cd Wait && periphery scan --project Wait.xcodeproj --schemes Wait --targets Wait --format xcode
```

- The scripts pass `-skipMacroValidation -skipPackagePluginValidation`, which TCA's macros need on the command line. Use the same flags if you call `xcodebuild` directly.
- The shared schemes are `Wait` (app, widget and embedded watch app) and `WaitWatch`. The `Wait` scheme has no test action; tests run through the package's auto-generated `WaitKit-Package` scheme.
- Test targets are `<Target>Tests` in `Wait/Packages/WaitKit/Tests`, one per source target, all using Swift Testing.
- SPM dependencies:
  - `Wait/Packages/WaitKit/Package.swift` has only Point-Free packages: TCA 1.26 (with the `ComposableArchitecture2Deprecations` trait), swift-dependencies, swift-sharing and swift-identified-collections.
  - `Wait/project.yml` still declares Money, Alamofire and SwiftyJSON, for the legacy watch app only, until plan 03.
  - Pins are in `Wait/Wait.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/Package.resolved`. Xcode refreshes it on the next resolve, because it still lists the removed packages.

## Architecture

### Targets
`Wait/project.yml` (XcodeGen; never hand-edit the pbxproj) generates three Xcode targets:
- `Wait`, which links `AppFeature`.
- `WaitWidgetExtension`, which links `Domain`, `DesignSystem` and `Persistence`.
- `WaitWatch`, which is still the legacy copy-based app until plan 03.

All other code lives in the local package `Wait/Packages/WaitKit` (iOS 17 / watchOS 10, Swift 6 language mode):

```
Domain              value types + ladder math: PriceLadder, Temperature, LadderStatus, WatchlistItem, Quote,
                    PriceSeries, ChartRange, MarketCalendar, PriceInput, WatchlistSnapshot, legacy decoders (no deps)
Logging             os.Logger channels: Log.app/.network/.persistence/.ui/.sync/.push/.connectivity
DesignSystem        -> Domain                         Palette, Spacing, StatusPill, TemperatureBadge
Persistence         -> Domain, Logging, Sharing, IdentifiedCollections, Dependencies
                    app-group files, @Shared(.watchlist) / @Shared(.checklistTemplate), mutation helpers,
                    SnapshotStore + SnapshotClient (\.snapshotClient), LegacyMigration
MarketDataClient    -> Domain, Logging, Dependencies  @DependencyClient (\.marketData) + CachingMarketDataClient + Twelve Data stopgap
ChecklistFeature    -> Domain, Persistence, DesignSystem, TCA         ChecklistFeature, ChecklistTemplateFeature
StockChartFeature   -> Domain, MarketDataClient, DesignSystem, TCA    StockChartFeature, ChartGeometry, StockChartView
StockDetailsFeature -> StockChartFeature, Persistence, MarketDataClient, DesignSystem, TCA
                    StockDetailsFeature, LadderEditorFeature, NotesEditorFeature
WatchlistFeature    -> StockDetailsFeature, ChecklistFeature, Persistence, MarketDataClient, DesignSystem, TCA
                    WatchlistFeature (Path: details, checklist), AddStockFeature
SettingsFeature     -> ChecklistFeature, DesignSystem, TCA
AppFeature          -> WatchlistFeature, SettingsFeature, Persistence, DesignSystem, Logging, TCA
                    AppFeature, AppView, DeepLink, AppDelegate (owns the store)
```

`Domain`, `Logging`, `DesignSystem` and `Persistence` also build for watchOS. `DesignSystem` guards its UIKit-backed dynamic colors with `#if os(iOS)`; on watchOS `Palette` uses the dark variants.

### Data flow
- **Source of truth.**
  - The watchlist is `@Shared(.watchlist)`: an `IdentifiedArrayOf<WatchlistItem>` stored in `watchlist.json` in the app group `group.chenkai.wait.contents`.
  - Mutate it only through the helpers in `Persistence/Shared+Watchlist.swift` (`update`, `add`, `remove`, `reorder`, `Shared<WatchlistItem>.update(now:)`). They stamp `updatedAt`, truncated to milliseconds.
- **Legacy data.**
  - `LegacyMigration` runs once, inside the lazy initializer of `AppDelegate.store`. The marker file `migration-v1.done` stops it running again.
  - It converts `Documents/stocks` (Money JSON) and the `checklist-*` files. The old files are left in place.
- **Price ladder.**
  - Anchors: `buyLow`, `buyHigh`, `fair`, `trim`, `sell`. `temperature(at:)` gives 0–100; `status(at:)` gives a `LadderStatus`.
  - The test vectors in `shared/ladder-test-vectors.json` are shared with the server tests. Change them only together with both test suites.
  - `PriceInput.parse` reads typed prices in the user's locale. A grouping separator is accepted only in a well-formed position (`1,234.5`), so `12.50` in `de_DE` is invalid, not 1250.
- **Market data.**
  - Features call `@Dependency(\.marketData)`. Its `liveValue` is `.cached(.twelveData(...))`, a stopgap until plan 04.
  - The Twelve Data key comes from the Info.plist key `TwelveDataAPIKey`, filled from the build setting `TWELVE_DATA_API_KEY` in the gitignored `Wait/Config/Secrets.xcconfig` (template: `Secrets.example.xcconfig`). `TwelveDataAPIKey.isUsable` rejects a missing, blank, unexpanded `$(...)` or placeholder key. The client then logs one error and every call throws `.unavailable` without making a request.
  - Read `.cacheOnly` first, then `.useCache`. Pull-to-refresh uses `.reload`.
  - TTLs follow NYSE hours (`CacheTTL`, `MarketCalendar`). After a 429, a cooldown makes every request serve from cache.
- **Widget.**
  - `AppFeature` publishes a `WatchlistSnapshot`, debounced 1 s, through `SnapshotClient`. That writes `snapshot.json` and calls `WidgetCenter.reloadAllTimelines()`.
  - The widget never touches the network.
- **Deep links.** `wait://stock/<SYMBOL>`.
- **Logging and credentials.** Log through `Log.<channel>` (subsystem `com.chenkai.wait`). No credentials live in source: `scripts/check-secrets.sh` fails on anything that looks like a hard-coded key.

### Presentation pattern
- Every screen is a TCA 1.26 `@Reducer` with `@ObservableState`.
- Navigation:
  - Stacks are `StackState` (`WatchlistFeature.Path`, `SettingsFeature.Path`).
  - Sheets and alerts are `@Presents`.
  - Child features report to their parents with `delegate` actions.
- Effects send back paired success and failure actions. A load that must not touch screen-level state sends its own action: `WatchlistFeature` sends `symbolQuotesLoaded` after adding one stock, so a rate-limit banner from the full-list load stays.
- Use the canonical TCA scope forms, because the package enables `ComposableArchitecture2Deprecations`: `Scope(\.child, action: \.child)`, `store.scope(\.child, action: \.child)` and `$store.scope(\.$destination, action: \.destination).case`.
- `.onChange(of:)` uses the effect-returning form `{ oldValue, state in Effect }` (see `AddStockFeature`, `AppFeature`). The reducer-builder overload is deprecated. It only sees mutations made by the reducer it wraps, so `AppFeature` attaches it outside `CombineReducers`.
- Tests use Swift Testing with `TestStore`, in `Packages/WaitKit/Tests/<Target>Tests`. Run them with `scripts/test-waitkit.sh`.

### watchOS app and connectivity

- The `WaitWatch` target (sources in `Wait/WaitWatch Watch App/`, bundle id `com.chenkai.wait.watchkitapp`, companion `com.chenkai.wait`) is embedded in the iOS app's `Watch/` folder. A watch compile error therefore breaks the app build.
- It still compiles its own **copies** of `Stock`, `StockCurrentQuote`, `TradeAction`, `TimeSection`, `Size` and `PriceHistory*`, with Money, Alamofire and SwiftyJSON from `project.yml`. Plan 03 rewrites it on top of WaitKit.
- `Shared/Connectivity.swift` is compiled into the watch app and wraps `WCSession`. The iOS app no longer uses it.

## Code style

The tools enforce this style through `Wait/.swiftformat` and `Wait/.swiftlint.yml`:

- 2-space indent. `case` is indented inside `switch`. No explicit `self`. Implicit returns. Line length is 180.
- SwiftFormat's `organizeDeclarations` and `markTypes` rules are on:
  - Each type is preceded by `// MARK: - TypeName`.
  - Members are grouped under `// MARK: Lifecycle`, `// MARK: Public`, `// MARK: Internal` and `// MARK: Private`, in that order.
  - Protocol conformances go in extensions marked `// MARK: ProtocolName`.
- File header, from `IDETemplateMacros.plist`:
  ```
  //
  // Created by: <name> on <date>.
  // Copyright © 2021 Wait. All rights reserved.
  //
  ```
